Octatrack base (beta): a sync that adds Ringmod SC (or any key-bus reader) no longer hangs in "publishing". When the same set also removed Sidechain and added an effect the project already uses, that effect started running before Ringmod SC's turn and took the DSP time the key bus's tap needed. The base refused Ringmod SC at every retry, the site gave up with "The Octatrack stopped answering", and undo was refused until a power cycle (beta finding 64). The tap's price is now checked when a package is admitted. Later in the same set the reader goes in, and its key bus waits for room, as an engine does. New beta base `5aef5f41`; Analog BD, Output Matrix and Sidechain are relinked to it with their code unchanged. Still open: a set whose rows are refused for another reason can still stall, and undo still can't remove a module a track is already running.
